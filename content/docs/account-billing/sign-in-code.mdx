title: Sign-in codes
description: Passwordless sign-in by email—a six-digit code, and what to do when email misbehaves.
updated: 2026-08-17
---

Nomu has no password to maintain. You enter your email, Nomu sends a **six-digit code**, and typing that code back into the app proves it is you.

The code lasts **10 minutes** and works **once**. If you ask for another one, the newest code is the only one that still counts.

<Callout title="Why a code and not a link">
  A code is typed on the device you are holding, so signing in never depends on
  your inbox opening the link on the right phone.
</Callout>

If anything goes wrong with delivery or timing, start with [I didn't receive the sign-in code](/troubleshooting/sign-in-code-not-received).
