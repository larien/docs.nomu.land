Good bug reports save everyone time. You do not need to be technical—just specific.

## Include

- **What you expected** vs **what happened** (one sentence each is fine).
- **Device** (phone model and Android version), and the Nomu version from **Profile**.
- **Rough time** (with timezone) so we can match logs.
- A **screenshot** if there is visible UI weirdness.

## Where to send it

Use in-app feedback, or email **support@nomu.land**. For **documentation** mistakes, use **Suggest an edit** at the bottom of any docs page to open a GitHub issue.
