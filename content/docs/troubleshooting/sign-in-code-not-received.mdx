Sign-in codes are simple until email gets in the way. Here is the order that fixes most people.

## 1. Check the boring folders

Look in **Spam**, **Promotions**, and **Updates**. Newsletters and auth emails often land there even when you have talked to the sender before.

## 2. Confirm the address

It is very easy to typo `gmail.com` vs `googlemail.com`, or to have an old address auto-filled. Request a new code and watch what address you actually submit.

## 3. Wait two minutes, then try once more

Email is usually fast, but not always. Ask for a second code after a short pause—not ten requests in a row. The newest code is the one that works.

## 4. Check the clock

A code expires **10 minutes** after it is sent. If the email surfaced late, ask for a fresh one rather than typing the old digits.

## 5. Rate limits

If Nomu recently sent you several codes, we may slow things down to protect your inbox from abuse. Wait **15–30 minutes** and try again with the correct email.

## 6. Still nothing?

Try another inbox you control, or another network (mobile data vs Wi-Fi) in case a corporate filter is eating unknown senders. If you are completely stuck, email **support@nomu.land** with the address you used (no need to paste the code).
